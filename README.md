# Práctica de integración continua con GitHub Actions

Proyecto de ejemplo para comprobar la ejecución automática de pruebas unitarias con Python, pytest y GitHub Actions.

## Ejecución local

```bash
python -m pip install -r requirements.txt
python -m pytest -v
```

## Integración continua

El workflow `Python CI` se ejecuta automáticamente con cada `push` y también puede iniciarse manualmente desde la pestaña Actions.
